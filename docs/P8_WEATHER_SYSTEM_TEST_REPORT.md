## 2. 天气状态模型

天气与季节正交：季节来自日历（isle_calendar / isle_season），天气只依据季节权重选择类型，不反向改变季节。

13 种类型（`TYPE_ORDER`）：
晴 / 多云 / 阴 / 有风 / 强风 / 小雨 / 中雨 / 大雨 / 小雪 / 中雪 / 大雪 / 雷暴 / 台风。

状态契约（`state()` 返回字典，供 HUD 与后续视觉消费）包含：
`type`、`label`、`mode`、`auto`、`manual_type`、`intensity`、`cloud`、`wind_dir`、`wind_strength`、`storm`、`precip_type`、`precip_intensity`、`transition`、`next_type`、`next_label`、`run_start`、`run_end`、`hold_left`、`hold_total`、`wetness`、`snow_depth`、`snow_trend`、`season`、`season_label`、`season_t`、`season_weights`、`available_types`、`seed`、`cal`。

- 降水类型：`precip_type` 取 `"none" / "rain" / "snow"`；`snow_depth` 只在下雪与低温季节累积。
- 湿润：下雨时以约 420 s 时间常数趋近目标，晴天以约 5400 s 蒸发；积雪累积约 9000 s、融化约 14000 s（模拟时间尺度）。
- 变化均连续（smoothstep 过渡），无瞬间硬切。

## 3. 自动调度规则

- 时间槽：`BLOCK_SECONDS = 1800`（30 模拟分钟）。每 10 个槽为一个"超级块"（5 游戏小时）。
- 轮次拆分：超级块内用确定性哈希 `_super_split` 切成 1~4 段（模式 [10] / [5,5] / [3,7] / [7,3] / [2,8] / [4,3,3] / [2,2,6]），即每轮天气持续 1~4 游戏小时。
- 轮次边界 O(1) 求解（`_run_bounds`），轮次首尾相接不重叠，避免轮内出现新起点造成类型硬切。
- 类型权重（`SEASON_WEIGHTS`，按四季权重连续混合）：
  - 冬季含三种雪（小雪/中雪/大雪），且台风权重为 0；
  - 夏季秋台风权重较高、雷暴权重最高；
  - 春季无雪、无台风；
  - 广州式艺术化气候：冬季自动下雪概率低，但允许出现；雪只作为冬季正常选项。
- 强度 `intensity = 0.25 + 0.65 * rnd`，并以此缩放 cloud/wind/rain/snow/storm；风向 `90 + 160 * rnd`（度）。
- 过渡：每轮结束前 `TRANSITION_SECONDS = 1200` 秒开始向下一轮混合；风向按最短弧插值，避免转向绕远路。
- 确定性：所有随机数来自 `_rand01(seed, index, salt)`（xorshift32，不使用会溢出的乘法），同 seed + 同一模拟时间必得同一状态；seed 默认 20261022，可由设置或 `--weather-seed` 覆盖。
- 跳日期/跨季：不补演历史事件，直接按目标时刻计算当前轮次并重新评估合法性；跨季时把不合法天气转换到合法类型（雪→雨、台风→雷暴/强风）。
- 暂停：`_paused` 时 `tick(..., advancing=false)` 冻结调度、过渡、湿润与积雪；手动切换仍立即生效。

## 4. 手动模式

- `set_mode("auto" | "manual")`；手动时 `set_manual_type(id)` 立即锁定，面板显示"手动锁定中 · 天气不会自行变化"。
- 手动列表按当前季节过滤：雪只列在冬季；台风只列在夏秋（夏季 10 项、冬季 12 项）。
- 跨季跳转后手动类型自动回退到合法类型（`_refresh` 中 `type_legal` 检查 + `_legal_fallback`），杜绝"夏季下雪"残留。
- 切回自动后按当前季节权重重抽，不强制延续手动类型。

## 5. 暂停 / 跳转语义

- 空格与 HUD 暂停按钮共享同一 `_paused` 状态（阶段 3 已完成），天气复用该状态：暂停时天气类型、过渡进度、cloud/wind、湿润与积雪均不推进。
- 日历跳转（`_jump_datetime`）后立即进入目标时刻的合法天气状态，不做补演、不累积中间过程。
- 现实时间模式下时间随系统时钟推进，但天气调度仍只基于模拟时间计算，不另建时钟。

## 6. 天气面板（HUD）

- 位置：左下角时间面板右侧，独立胶囊 + 可折叠面板；不遮挡天文历与性能面板。
- 胶囊：`☁ 天气  <当前类型>`，与时间胶囊并列。
- 面板内容：
  - 当前类型（大字）、`季节 · 自动/手动 · 强度 N%`；
  - 自动模式显示"预计再持续 X 小时 Y 分 · 本轮共 …"；手动模式显示"手动锁定中"；
  - 过渡提示与趋势（`趋势 · 持续小雨` 等）；
  - 模式切换按钮（自动/手动，当前模式高亮）；
  - 手动类型网格：仅列本季合法选项，4 列，当前类型高亮；
  - 底部说明"天气只影响观感，不改变任何进度 · W 收折"。
- 交互：W 键或胶囊开合；14 秒无操作自动收折；H 隐藏界面时同步收起；不阻断时间面板、天文历与相机操作。
- 面板尺寸经截图实测收紧（`WEATHER_PANEL_TOP = -338`），12 个类型 3 行时无多余空白；右上按键提示因新增 W 键加宽到 400 px 并左移，避免超出屏幕右缘。

## 8. 性能与开销

- 天气状态机每帧仅做常数级计算（轮次边界 O(1)、少量插值与标量运算），不分配节点、不重建几何；
- 面板文字仅在 HUD 0.12 s 刷新节流内更新，类型网格只在可用类型集合变化时重建；
- 视觉开销（雨雪粒子、积雪、风场）在阶段 6 实现，届时另行测量并写入性能对比。

## 9. 已知限制与后续

1. 本阶段只做状态与面板；"下雨/下雪/台风"目前只改变面板文字与内部参数，画面观感待阶段 6。
2. 无天气音效（雨声/风声）；若后续加入需复用现有 isle_audio 总线，不新增音频资产类别。
3. 天气种子固定后同日期结果可复现；切换 seed 会改变历史轮次，但不会回溯已经发生的湿润/积雪（从当前状态继续）。
4. 运行日志中的 `f.is_null() at _save_to_cache (shader_rd.cpp:696)` 与日志轮转失败、根证书读取失败均为既有环境问题（user:// 写入受限），与本阶段改动无关。
5. 手动模式不提供"强度"滑条，强度由类型参数与自动强度决定；如后续需要单独调节，需在天气面板增加强度档位并保持本季合法约束。
