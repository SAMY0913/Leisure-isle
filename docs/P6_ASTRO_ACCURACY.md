## 2. 太阳：NOAA Solar Calculator 算法

`scripts/isle_astro.gd` 中 `_sun_equatorial(jd)` / `sun_position(jd)`：

1. **儒略日与世纪数**：`jd_from_local()` 用 `(local_seconds - 28800)/86400 + 2440587.5`；`T = (jd - 2451545.0)/36525`。
2. **平黄经/平近点角**：`L0 = 280.46646 + 36000.76983 T + 0.0003032 T²`；`M = 357.52911 + 35999.05029 T - 0.0001537 T²`。
3. **中心差**：`C = (1.914602 - 0.004817 T - 0.000014 T²) sin M + (0.019993 - 0.000101 T) sin 2M + 0.000289 sin 3M`。
4. **真黄经 / 视黄经**：`true_lon = L0 + C`，减章动与光行差修正 `0.00569 + 0.00478 sin Ω`（Ω = 125.04 - 1934.136 T）。
5. **黄赤交角**：`eps0 = 23.439291 - 0.0130042 T - 1.64e-7 T² + 5.04e-7 T³`，加 `0.00256 cos Ω` 得真交角。
6. **赤经/赤纬**：标准黄道→赤道公式，`dec`、`ra`；太阳距离 `R = 1.000001018 (1 - e²)/(1 + e cos ν)`（e 用 T 修正）。
7. **地平坐标**：`_horizon(dec, ha)`：`ha = gmst + LON - ra`，`az = atan2(-cosδ sinH, sinδ cosφ - cosδ sinφ cosH)` 归一到 0..360，`alt = asin(sinφ sinδ + cosφ cosδ cosH)`。**用 atan2 形式避免 acos 在极值处抖动，保证 24h 连续。**
8. **event 阈值（大气折射）**：
   - 日出/日落：太阳中心几何高度 **-0.8333°**（= 折射 34′ + 半径 16′），插值到秒；
   - 民用晨昏：**-6°**；航海晨昏：**-12°**；天文晨昏：**-18°**。
9. 正午：用 `_sun_ha_at(jd)`（时角过零）二分，得到太阳上中天时刻、高度、方位。

## 3. 月亮：Meeus *Astronomical Algorithms* 第 47 章

`scripts/isle_astro.gd` 中 `_moon_with_sun(jd, sun, lr_terms, b_terms)`：

1. **主要周期项**：完整录入 Meeus 表 47.A（黄经 60 项 + 距离 60 项，扁平数组 `_MOON_LR`，每组 `[D, M, M', F, Σl, Σr]`）与表 47.B（黄纬 60 项，`_MOON_B`，每组 `[D, M, M', F, Σb]`）。
2. **偏心率修正**：`E = 1 - 0.002516 T - 0.0000074 T²`，按 M 的系数（0/±1/±2）乘 `E^|M|`。
3. **附加项**：A1 = 119.75 + 131.849 T（金星）、A2 = 53.09 + 479.264 T（木星）、A3 = 313.45 + 481.266 T（月球近地点）修正黄经/黄纬。
4. **章动**：Δψ/Δε（Meeus 简化章动级数），黄经加 Δψ。
5. **黄道→赤道**：得 RA/Dec；再与太阳位置一起算地心黄经差。
6. **地平视差**：Meeus 40.2 / 40.3，得视差角 `parallax ≈ 0.95°`（随距离变化），站心（topocentric）高度/方位修正；半直径 `sd ≈ 0.259°`。
7. **照度/月相**：相位角 `i = atan2(r_s sinψ, Δ - r_s cosψ)`，照度 `illum = (1 + cos i)/2`；`waxing = fposmod(lon_moon - lon_sun, 360) < 180`（黄经差符号）。
8. **月出/月没阈值**：站心几何高度 **-(0.5667° + sd)** ≈ -0.83°（= 地平折射 34′ + 月半径；对应地心几何高度约 +0.12°，与「视差 ≈0.95° 修正后」的常见 -0.125° 阈值等价）。月出/月没方位用完整模型 `moon_position()` 在事件时刻再算一次。
9. **跨日**：`day_events` 只返回**本地日内**的月出/月没，缺席返回 `-1`（与旧版一致；跨日事件请用相邻日期查询）。

## 4. 事件求解与性能（`day_events`）

- **旧版瓶颈**：每 2 分钟 721 点线性插值，每点全量 NOAA+Meeus → 10~14ms。
- **新版**：
  1. 太阳粗采样 **49 点 / 30 分钟**（只用 `_sun_alt_at`），过零区间做 **10 次二分**（分辨率 30min/1024 ≈ 1.76s）；
  2. 正午用 `_sun_ha_at` 二分 10 次；
  3. 月亮粗采样 **5 点 / 6 小时**用截断模型（24+12 项，固定 sd）判符号，过零区间用**试位法 4 次迭代**细化（含视差/半径动态阈值）；
  4. 月亮粗采样与 noon_illum 用 `_moon_fast()`（截断级数 24+12 项）；事件方位仍用完整 60+60 项模型。
- **截断级数误差**（截断 vs 完整模型，10 日期每 5 分钟采样）：高度 0.0254°、方位 0.2803°、照度 0.00014；对升落时刻影响 < 0.1 分钟（见 §6 月亮误差）。
- **实测**（headless，Godot 4.7.2，本机）：

| `day_events` 冷启动（10 个不同日期） | **avg 2.39ms / max 3.13ms**；重复 3 轮 avg 2.10 / 1.93 / 2.93ms，max 4.13ms | < 5ms |

## 7. 坐标映射审计（世界 / 相机 / HUD）

**结论：天空与光方向的映射正确，无需补偿；HUD 罗盘 heading 公式存在东西镜像 bug，需 main.gd 一处修改（Lead 执行）。**

1. **世界约定**：`IsleMath.sun_dir(alt, az) = (cos alt·sin az, sin alt, -cos alt·cos az)` → az=0 → -Z（北），az=90 → +X（东）。`compute()` 返回 az 自北顺时针，两者一致。
2. **天空 shader**：`shaders/sky.gdshader` 内 `vec3 d = normalize(EYEDIR)`，方位反解 `atan(d.x, -d.z)`，与上面同一约定；main 传世界向量 `sun_dir`/`moon_dir` 正确。
3. **场景整体变换**：`world.gd` 的 holder/Island 根节点无旋转（identity）；`cottage.gd` 仅小屋根节点 rotation.y=0.30，不是整岛旋转 → 世界方向无需父变换补偿。
4. **相机**：`main.gd::_pose_to_transform`：`pos = target + (r cos(elev) sin θ, r sin(elev), r cos(elev) cos θ)`，basis 的 -Z 指向 target。θ=0 时相机在 +Z 看向 -Z（世界北）。
5. **HUD 罗盘 bug**：`hud.gd::_draw_compass` 把卡片字母放在 `rel = card_bearing - heading`，即 `heading` 必须是「视线地面真方位」。main.gd L830-831 旧式：

```gdscript
var yaw := atan2(dir.x, dir.z)
var heading_deg := fposmod(rad_to_deg(yaw) + 180.0, 360.0)
```

这是**东西镜像**（probe 数值）：

| 相机 θ（绕 Y，+Z→+X 方向） | 视线真方位 | 旧公式 heading | 修复后 heading |
| ---: | ---: | ---: | ---: |
| 0° | 0° | 0° | 0° |
| 45° | 315° | 45° | 315° |
| 90° | 270° | 90° | 270° |
| 180° | 180° | 180° | 180° |
| 270° | 90° | 270° | 90° |

修复（`dir = _cam_target - _cam.global_position`）：

```gdscript
var heading_deg := fposmod(rad_to_deg(atan2(dir.x, -dir.z)), 360.0)
```

> 该 bug 属于 main.gd（Lead owner），本任务只提供结论与精确公式，未改 main。Lead 已于 2026-10-20 合入该公式（main.gd L849-851），并用统一 `--shots` 截图从渲染侧确认（见 §6.6：罗盘显示 115°/244°/244°/317°，与旧镜像公式的 244°/116°/116°/42° 相反）。
