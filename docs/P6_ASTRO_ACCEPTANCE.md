## 2. 输入输出约定（从 isle_astro.gd 代码确认）

| 项 | 约定 |
| --- | --- |
| 地点 | LAT=23.1291°N，LON=113.2644°E，固定 UTC+8（TZ=28800s，无夏令时） |
| 时间输入 | `local_seconds` = 本地日 00:00 起的秒数（非 Unix epoch） |
| 儒略日 | `jd_from_local(s) = (s - 28800)/86400 + 2440587.5`（固定按 UTC+8 反推 UTC） |
| 角度单位 | 对外全部为**度**（内部赤道/地平计算用弧度后转回） |
| 方位角 | 从**正北起顺时针** 0..360（0=N，90=E，180=S）；`atan2(-cosδ sinH, sinδ cosφ - cosδ sinφ cosH)` 归一到 [0,360) |
| 高度角 | **几何高度**：太阳不减大气折射；月亮先做地心→站心视差修正（Meeus 40.2/40.3）后仍为几何高度 |
| 世界坐标映射 | `IsleMath.sun_dir(alt,az) = (cos alt·sin az, sin alt, -cos alt·cos az)`，az=0→(0,0,-1) 北 |
| 太阳升落阈值 | 中心几何高度 **-0.8333°**（折射 34′ + 半径 16′） |
| 月亮升落阈值 | 站心几何高度 **-(0.5667° + sd)**，sd 由当日地心距推导（约 -0.82°…-0.85°） |
| 晨昏阈值 | 民用 -6°、航海 -12°、天文 -18° |
| 求根方式 | 太阳：当日 49 点 / 1800s 网格 + 二分（插值到秒）；月亮：5 点 / 6h 网格 + 试位法 4 次；正午 = 时角过零二分 |
| 缓存 | `day_events` 只缓存**当前本地日**一份；换日自动重算；跨日事件（如跨午夜月出）通过相邻日期查询 |
| 月亮距离 | `moon_dist` 为**地心距** = 385000.56 + Σr/1000（Meeus 47.A 60 项，km） |
| 月亮相位 | `moon_illum=(1+cos i)/2`，`moon_phase_angle`=日月地相位角，`moon_waxing`=月日黄经差 <180 |

## 3. 参考实现与口径差异（已量化，不是放宽）

| 差异 | 说明与处理 |
| --- | --- |
| NOAA 是「太阳专用」实现 | NOAA solcalc 用其自身的 ΔT/几何近似，与 AE 的太阳方向最大差 0.01465°（方向夹角）。两参考都作为独立参照，双列给出。 |
| AE `Equator(observer).dist` 是站心距 | isle_astro 的 `moon_dist` 是地心距。直接比会差最大约 6378km（地球半径投影）。**改法**：`gen_ref_t7.js` 用 `GeoVector(Moon).Length()*KM_PER_AU` 提供地心距基准 `moon_dist_geo_km`；探针侧另加自检「站心-地心差 ≤ 地球半径(6378.2km)」，实测 0 超出。 |
| 方位角近天顶病态 | alt→90° 时 az 坐标敏感度 1/cos(alt) 发散，az 差不能代表指向差。**判据**：以单位方向向量夹角为绑定判据（太阳 0.05°、月亮 0.1°），az 判据只统计 alt<80° 的可观样本；正午 az 只统计 noon_alt<85°。另：参考装置自检的 az 项（NOAA vs AE 方向夹角 0.01465° 而 az 差 0.0342°）标为 INFO 展示，绑定自检判据是方向夹角 ≤0.02°。 |
| NOAA 正午高度来自 1min 网格最大值 | 与真实中天有量化误差，容差单列 0.2°；与 AE transit 的直接比较容差 0.1°。 |

## 8. [KNOWN-BUG] 现实时间模式切换显示时区会平移天体地理位置（位于 main.gd，非天文模型）

实测（基准 unix=1773968400 = 2026-03-20T01:00Z，同一物理时刻仅换显示时区）：

| 显示时区 | 偏移 | 显示当地时刻 | sun_alt | sun_az | jd |
| --- | --- | --- | --- | --- | --- |
| Asia/Shanghai | +28800s | 09:00 | 32.9373° | 106.3676° | 2461119.541667 |
| Asia/Tokyo | +32400s | 10:00 | 45.8032° | 116.4199° | 2461119.583333 |
| America/New_York | -14400s | 21:00 | -33.2072° | 285.6649° | 2461119.041667 |

→ max|dalt|=**66.1445°**、max|daz|=**179.2974°**。天体位置不应随显示时区变化（用户硬性要求）。

根因：`main.gd` real 模式令 `_sim_seconds = _abs_unix + 所选时区偏移`，而 `isle_astro.jd_from_local()` 固定减 28800（假定 UTC+8），非 UTC+8 时区把显示偏移直接灌进天文层。

建议 patch（待 Lead 决定；本探针/本报告未改源码）：
- real 模式向天文层传 `_abs_unix + 28800`（或让 isle_astro 接收 Unix 时间戳直接算 jd）；
- `_local_seconds_to_display_text` 的 real 分支改为与 sim 分支同式：`local - 28800 + 所选偏移`；
- 同步修改 `main.gd` _selftest 第 24 项（其当前断言 sky == 显示时区墙上时刻，与该语义一致但与“地理不变”冲突）。

状态：**未修复/未验证修复**（不在本 teammate scope；isle_astro.gd 本身在所有交叉校验中通过）。模拟模式下该问题不存在（通过）。
